# Maths Practice (Years 4-10)
Static PWA for GitHub Pages. English / Simplified Chinese. No server, no API key.
Publish: push to a repo, Settings > Pages > Deploy from branch `main` / root. Bump `V` in `sw.js` after every update.
Files: `i18n.js` (all text), `engine.js` (question generators + answer checking), `app.js` (screens), `style.css`.
Progress and the parent PIN are stored only in this browser (the PIN is a child lock, not strong security).
